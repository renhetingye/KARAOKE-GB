## 4. ユーザーにお願いする操作（実機確認）
ソフトウェア側の自動実装・自動ベンチマークはすべて完了しました。
現在、ユーザーにしかできない唯一の作業は**「マイクに声を出す・返ってくる音を確認する」**ことです。
以下のいずれかの方法でご確認いただけます：

1. **CLI でのリアルタイム確認（声出し・音高表示）**:
   ```powershell
   target\debug\karaoke-cli.exe stream-mic 5
   ```
   マイクに向かって「あー」と声を出すと、検出された音高（Hz・MIDI音名・周期性・RMS）がリアルタイム表示されます。

2. **GUI アプリでの確認（画面上で音程バーと光点を確認）**:
   ```powershell
   cd apps/desktop
   npm.cmd run tauri dev
   ```
   画面が起動したら「Start Live Microphone Test」をクリックしてマイクに発声してください。Canvas 2D ピアノロール上にリアルタイムであなたの歌声の光点と軌跡が流れます。
