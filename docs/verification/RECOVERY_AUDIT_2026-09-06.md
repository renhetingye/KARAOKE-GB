# Recovery audit — 2026-09-06

## 発見した主要原因

1. Real-time PitchFrameのQPCをSong timeとして採点していた。
2. 5.33msごとに全曲セルと全履歴frameを再走査し、計算量が時間とともに増加していた。
3. AI解析が現行譜面を直接上書きし、短音を時間閾値だけで削除していた。
4. 保存がrevision確認なしの直接 `fs::write` だった。
5. UIの「キー変更」は表示ノートのみを動かし、音源・Rust採点へ適用されていなかった。
6. PowerShell launcherは変数が欠落して構文エラーだった。

## 回復方針

- 正本v4の時刻、固定分母、欠落状態、候補分離、revision保護へ戻した。
- ユーザーの既存現行譜面は自動採用せず、そのまま保全した。
- 合成テストのPASSを実機測定の代用にしない。

詳細な変更・検証結果は `docs/PROGRESS.md` を参照。
