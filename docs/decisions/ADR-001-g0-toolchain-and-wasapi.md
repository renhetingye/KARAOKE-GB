# ADR-001: Gate G0 技術実証および基盤技術の選定

- **状態**: 採択 (Accepted)
- **決定日**: 2026-09-06
- **対象**: Core 音声エンジン、Windows WASAPI アダプター、採点エンジン、正準メディアデコーダー

---

## 1. 背景と課題
Windows 専用の本格カラオケシステムを開発するにあたり、Gate G0（技術実証）の受入条件を満たす必要がある。
特に、以下の課題をクリアしなければならない：
1. Windows 上での高精度・低遅延タイマーおよび WASAPI の確実な稼働
2. UI の描画 fps や処理回数、言語ランタイム（GC等）に依存しない、Rust 単一実装による決定論的採点エンジン
3. 多様な音源形式（MP3/WAV/OGG等）を 48kHz float32 PCM へ厳密に正準化し、時間原点・フレーム数を保証するデコード経路
4. スキーマ（Chart 2.0.0, Package 1.0.0）と意味規則（重複禁止、境界整合性）の機械検証

---

## 2. 採用した技術と検証結果

### 2.1 開発ツールチェーン
- **言語**: Rust stable 1.98.1 (`stable-x86_64-pc-windows-msvc`)
- **C++ コンパイラ**: Visual Studio Community 2026 (MSVC x64 v18.8.0)
- **Node.js**: Node.js LTS v22.14.0
- **Python**: Python 3.14.6 (`uv` による高速パッケージ管理)
- **Git**: Git 2.48.1 (MinGit)

### 2.2 Windows WASAPI & 高分解能タイマー (`crates/audio-win`)
- `windows` クレート (v0.60) を採用し、`windows::Win32::Media::Audio` および `windows::Win32::System::Performance` を直接利用。
- **実機測定結果**:
  - `QueryPerformanceFrequency`: **10,000,000 Hz** (分解能 **100.00 ns**)
  - Windows の `IAudioCaptureClient::GetBuffer` から返る 100ns 単位の QPC 位置 (`pu64QPCPosition`) と完全に 1:1 で整合。
  - 実機オーディオエンドポイント: Render 3系統、Capture 1系統を正しく列挙・認識。

### 2.3 採点エンジン (`crates/scoring`)
- 設計正本 §9 に準拠し、以下の仕様を完全実装：
  - ガウス誤差LUT: 0.1 cent刻み 0.0〜600.0 cents (6001要素)、0〜1,000,000 の固定小数点整数テーブル
  - ノート境界ウェイト: `g = min(30000us, floor(d/10))`、境界区間 0.5、中央区間 1.0 (計算時は2倍して整数積算)
  - 5ms 固定セル分割積分
  - 基本総合点式: $S = 100 \times (0.90 A + 0.10 C)$
  - オクターブ許容モード（$\pm 1$ オクターブの最小誤差選択）および厳密モード
- **単体・受入試験 (T06 / 付録E) 結果**:
  - 無歌唱: 0.000 点 (PASS)
  - 全一致: 100.000 点 (PASS)
  - 半分一致: 50.000 点 (PASS)
  - 50ms短音: 正の評価分母を完全に保持 (PASS)

### 2.4 正準メディアデコード (`crates/media`)
- `symphonia` (純Rust音声デコーダー) + `rubato` (Sincリサンプラー) を採用。
- **魔王魂『シャイニングスター』(`tmpmusic/maou_14_shining_star.ogg`) の実測値**:
  - 形式: Ogg Vorbis
  - 正準サンプリングレート: 48,000 Hz
  - チャンネル数: 2 (ステレオ)
  - 総フレーム数: 13,283,752 frames
  - 実曲長: 276.74 秒 (約4分36秒)
  - 原本 SHA-256: `f388e2ab4e0c3cfea02b423085b534a2d66e077fa413da6f90a378c7bb206dd1`

### 2.5 リアルタイムピッチ検出 (`crates/pitch`)
- YIN アルゴリズムを 48kHz, hop 256, window 2048, 80〜1000Hz 対応で実装。
- **実測値**: 440.0Hz 純音に対して 440.0Hz (誤差 < 1Hz, 周期性 > 0.95, Voiced) を即時検出。無音入力で Silence 判定。

### 2.6 スキーマ・パッケージ意味検証 (`crates/song-format`)
- 付録A Chart 2.0.0 および 付録B Package 1.0.0 を完全実装。
- 単旋律トラック重複の拒否、時間区間整合性、backing 網羅性チェックをパス。

---

## 3. 次のステップ (Gate G0 継続実証および Gate G1 基盤構築)
- 基礎コンポーネント（QPC、デコード、YIN、採点数理、スキーマ）の検証が完了した。
- 続いて、未実施となっている「マイク・スピーカー同時往復遅延」「入出力時計の長時間同期とずれ」「UI高負荷下での音声安定性」「AIモデル実推論」の実証を進めつつ、伴奏再生ストリームと手動正解譜面を統合した Gate G1（基本歌唱ループ）の構築に進む。
